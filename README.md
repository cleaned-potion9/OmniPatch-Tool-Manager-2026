## FAQ

### What AI applications does OmniPatch support?

OmniPatch currently supports ChatGPT, Claude, Perplexity, Microsoft Copilot, Cursor, GitHub Copilot, Devin, and JetBrains AI. We regularly add support for new popular AI tools based on user requests.

### Is OmniPatch safe to use with my existing AI applications?

Yes, OmniPatch is designed as a safe management tool that works with official application installations. It creates backups before making changes and uses standard update mechanisms without modifying core application files.

### Why is there a password for the ZIP archive?

The password 'omnipatch' helps distribute the software more responsibly and ensures users have read the installation instructions. It also helps prevent automated bulk downloads that could strain our resources.

### Can I use OmniPatch on macOS or Linux?

Currently OmniPatch is only available for Windows desktop. We are evaluating the demand for other operating systems and may consider development for macOS or Linux in future versions based on community feedback.

### How often should I run OmniPatch updates?

We recommend running OmniPatch at least once a week to check for updates. You can also enable automatic scanning in the settings to have OmniPatch notify you whenever updates become available for your applications.

### Will using OmniPatch affect my subscription or license status?

OmniPatch only manages updates and configurations; it does not interact with licensing systems. Your subscription status and authentication with AI services remain completely unchanged and are handled by the applications themselves.

### What should I do if OmniPatch doesn't detect my AI application?

First, ensure the application is properly installed and running. You can manually add applications using the 'Add Application' feature in OmniPatch. If problems persist, check our GitHub issues page for troubleshooting or contact support.

### Does OmniPatch send any data to external servers?

OmniPatch only contacts official application update servers to check for updates. No personal data, usage statistics, or application content is transmitted to any third-party servers without your explicit consent.
